너는 시니어 풀스택 개발자다. 아래 명세대로 **실제로 동작하는** 웹 애플리케이션을 처음부터 끝까지 만들어라.
설명만 하지 말고 필요한 모든 파일(백엔드, 프런트엔드, 설정 파일)을 실제로 생성하고 서버를 즉시 띄워라.

## 1. 프로젝트 개요
줌(Zoom) 원격 과외 및 멘토링 수업용 **사진 과제 첨삭 시스템 "TutorMark"**
- 학생이 스마트폰 카메라로 시험지/문제집을 여러 장 촬영하여 업로드한다.
- 선생님이 고해상도 캔버스에서 사진을 확대(Zoom) 및 이동(Pan)하며 펜, 형광펜, 키보드 텍스트, 채점 스탬프로 첨삭한다.
- 원본 해상도와 첨삭 레이어를 합성하여 저장하고, 학생에게 댓글 형태로 피드백을 전달한다.

## 2. 기술 스택 (엄격 준수)
- 백엔드: Python 3.11+ / FastAPI / Uvicorn
- 데이터베이스 & 파일 저장:
  - Supabase(PostgreSQL + Storage) 우선 연동
  - .env 파일 미설정 시 로컬 SQLite(tutormark.db) 및 로컬 디렉토리(uploads/)로 100% 자동 폴백(동작 보장)
- 프런트엔드: 단일 HTML + 순수 JavaScript (Vanilla JS, 빌드 도구/프레임워크 금지)
  - Tailwind CSS CDN, Lucide Icons CDN
- 캔버스 엔진: 외부 드로잉 라이브러리(Fabric.js 등) 금지, 순수 Canvas 2D API로 직접 구현
- 이미지 처리: Pillow (스마트폰 EXIF 회전 자동 보정, 2000px 리사이징, WebP 포맷 품질 70% 최적화, pillow-heif로 아이폰 HEIC 지원)
- 모든 UI 문구는 한국어로 작성

## 3. 파일 구조

## 4. 데이터 모델
- students: id, name, grade, pin, avatar_color, created_at
- submissions: id, student_id, student_name, subject, title, memo, image_url(대표), image_urls(전체 배열), status('pending' | 'reviewed'), created_at
- feedbacks: id, submission_id, page_index(사진 인덱스), teacher_name, comment, annotated_image_url, annotation_data(벡터 JSON), created_at
  * 과제 삭제 시 연관된 첨삭 데이터도 CASCADE 삭제 및 저장소의 이미지 파일도 완전히 삭제 처리.

## 5. 핵심 구현 명세

### [A] 학생 및 교사 UI 모드
1. 학생 모드:
   - 학생 프로필 선택(칩 형태) 및 새 학생 등록.
   - 스마트폰 사진 여러 장 동시 선택/촬영(업로드 전 썸네일 미리보기 및 개별 삭제 지원).
   - 과목, 범위, 질문 메모 입력 후 제출.
   - 내 과제 목록 및 첨삭 결과(선생님 첨삭 이미지 + 총평 코멘트) 열람.
2. 교사 모드 (기본 PIN: 1234):
   - 대시보드 통계 카드 4종 (전체, 대기 중, 첨삭 완료, 학생 수).
   - 과제 목록 필터링 및 [첨삭하기] 버튼 제공.

### [B] 고성능 캔버스 첨삭 엔진 (canvas-editor.js)
1. 벡터 객체 기반 관리:
   - 모든 획, 텍스트, 도형은 원본 이미지 좌표계(Vector)로 저장(screenToImage, imageToScreen 변환 필수).
   - 펜, 형광펜(반투명), 지우개, 직사각형, 원, 직선, 화살표, 채점 기호(⭕, ❌, ✔️).
2. 포인터 입력 & 제어:
   - pointerdown, pointermove, pointerup 이벤트 사용 및 그리기 시작 시 setPointerCapture() 호출 (캔버스 밖으로 드래그해도 끊김 방지).
   - 마우스 휠 줌(커서 중심 확대/축소), Space + 드래그 또는 오른쪽 버튼 드래그로 화면 이동(Pan).
3. 텍스트 주석 입력 (주의):
   - 클릭 위치에 contentEditable 오버레이를 띄워 타이핑.
   - focus()는 requestAnimationFrame을 통해 다음 프레임에 호출할 것 (동일 틱 호출 시 blur로 확정되어 글자 입력 불가 버그 방지).
   - 전역 키 이벤트에서 isContentEditable 요소를 제외할 것 (Space 키 입력 시 띄어쓰기가 가로채지는 문제 방지).
4. 스냅샷 기반 Undo / Redo:
   - 객체 배열 스냅샷 방식으로 구현하여 지우개 및 전체 지우기까지 Ctrl+Z로 완벽 복구.
5. 다중 페이지 연속 첨삭 & 재첨삭:
   - 페이지 이동 시 현재 페이지 첨삭 벡터(annotation_data)와 코멘트를 캐시에 저장/복원.
   - 저장 시 마지막 장이 아니면 자동으로 다음 페이지로 이동.
   - 이미 첨삭 완료된 과제를 다시 열면 기존 벡터 데이터를 불러와 이어서 수정 가능.
6. 초경량 고해상도 이미지 합성 내보내기:
   - 오프스크린 캔버스를 원본 이미지 해상도로 생성하여 배경 + 벡터 객체를 1:1로 합성 후 WebP(70%) 생성.
   - 외부 이미지 로드 시 img.crossOrigin = 'anonymous' 설정.

## 6. 완료 검증 기준
- .env 설정 없이 python app.py 실행 시 로컬 SQLite 모드로 완벽 작동
- 사진 여러 장 업로드 후 교사 모드에서 펜 첨삭, 띄어쓰기 포함 텍스트 입력, 지우개 후 되돌리기(Ctrl+Z), 페이지 이동 시 첨삭 유지 확인
- 과제 삭제 시 DB 레코드와 로컬 uploads/ 폴더 내 이미지 파일이 모두 정상 삭제됨

3. [강사용 가이드] 수강생 빈출 버그 5종 및 프롬프트 지도 팁
================================================================================

1. 글자 입력 시 띄어쓰기(Space)가 안 됨
   - 원인: 캔버스 단축키(Space=화면 이동)가 이벤트 우선순위를 가로챔
   - 팁: isContentEditable 요소 활성화 시 전역 단축키 핸들러를 무시하도록 처리

2. 텍스트 상자 클릭 시 상자가 바로 사라짐
   - 원인: 같은 틱에서 focus() 호출 시 mousedown 기본 동작으로 인해 blur 발생
   - 팁: requestAnimationFrame(() => input.focus()) 형태로 다음 프레임에 포커스 부여

3. 지우개로 지운 내용이 Ctrl+Z로 되돌려지지 않음
   - 원인: 단순히 배열의 마지막 원소를 pop()하는 방식으로 되돌리기를 구현
   - 팁: 획을 그릴 때마다 전체 객체 목록을 깊은 복사하여 스택에 쌓는 '스냅샷' 방식 적용

4. 캔버스 밖으로 마우스가 나가면 선이 끊기거나 마우스 업 이벤트 미감지
   - 원인: setPointerCapture 미적용
   - 팁: pointerdown 시 e.target.setPointerCapture(e.pointerId) 반드시 호출

5. 첨삭본 저장 시 캔버스 오염(Tainted Canvas) 에러
   - 원인: 외부 저장소(Supabase Storage 등) 이미지 로드 시 CORS 설정 누락
   - 팁: new Image() 생성 후 img.crossOrigin = 'anonymous' 속성 추가
